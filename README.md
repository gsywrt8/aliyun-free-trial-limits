## “免费3个月”实际能用多久？

试用期确实有3个月，但额度是另一道闸门。计费逻辑是：试用实例按量计费，费用从免费额度里扣，额度扣完，超出部分开始正常收费。3个月只是额度不再补充的最长窗口。

官方文档给过一道现成的算术题：实例每小时0.833元时，300 ÷ 0.833 ÷ 24 ≈ 15天。也就是说，顶格用满个人版每小时免费上限的配置，半个月额度就见底。反过来，实例每小时价格越低，额度撑得越久，公式就一条：免费时长 ≈ 300元 ÷ 实例每小时价格。

开多台机器要盯住每小时上限：所有实例每小时的费用加起来一旦超过0.833元（企业版1.833元），超出部分直接计费，不会因为“还在试用期”就免单。ECS控制台概览页的“我的试用进度”区域能看到试用时间余量和额度余量，收到“额度不足20%”的提醒时，就该收着用了。

## 常见问题

**为什么我领取试用时提示不符合条件？**
按顺序排查五件事：账号是否完成实名认证；该账号以前是否试用或购买过ECS；是否有同人关联账号已经参与过活动；是否从试用中心页面进入开通——从其他开通页面进去无法参与免费试用活动；账户是否存在欠费。

**试用到期后会自动续费吗？**
不会自动续费，但也不会自动停机。到期后实例转入按量付费模式继续计费，直到你手动释放或转为正式购买。

**多开几台实例还能免费用吗？**
可以，个人版累计上限6台、企业版同样累计上限6台，但所有实例每小时的费用总和不能超过免费上限（个人版0.833元/小时，企业版1.833元/小时），超出部分照常计费。

**试用实例能做ICP备案吗？**
不能。按量付费模式暂不满足国内站ICP备案要求，需要备案的网站请购买包年包月实例。

**免费流量用完了怎么办？**
超出每月220GB免费额度的流量需要自行承担，具体用量和账单可以在费用与成本控制台里查询。
